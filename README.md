# VoxGraph Web

[![Next.js](https://img.shields.io/badge/Next.js-14-black?logo=next.js)](https://nextjs.org/)
[![Deployed on Vercel](https://img.shields.io/badge/Vercel-deployed-black?logo=vercel)](https://voxgraph-web.vercel.app)

Marketing site, interactive documentation, and browser **Try** demo for [VoxGraph](https://github.com/suryaraj05/voxgraph).

**Live:** [voxgraph-web.vercel.app](https://voxgraph-web.vercel.app) · **Docs:** [/docs](https://voxgraph-web.vercel.app/docs)

| Route | Purpose |
|-------|---------|
| `/` | Marketing home with pipeline diagram |
| `/docs` | Developer guides + interactive architecture diagram |
| `/try` | Voice demo (local or online Render backend) |

## Local dev

```bash
npm install
cp .env.example .env
npm run dev
```
